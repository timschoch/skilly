# marketing-shop

Marketing for online shops, subscription shops above all: `marketing` (texts, SEO, conversion) plus retention and lifecycle from coreyhaines31/marketingskills.

- `churn-prevention` — cancel flows, save offers, pause instead of cancel, failed-payment recovery.
- `emails` — lifecycle flows (welcome, post-purchase, win-back): which mails, triggers, timing. `lemy-write` writes their copy.
- `referrals` — refer-a-friend and affiliate programs.

Left out (2026-10-05):

- `schema` — shop themes already emit product structured data; `seo-audit` catches gaps.
- `launch`, `pricing`, `product-marketing` — one-off work; add the single skill when it comes up.
- `content-strategy` — only for shops that run a blog.
