# tech-lemy

Ships `lemy-write` from `timschoch/lemy`, plus the Router rule `tech-lemy-write.md`. `lemy-write` is the one writing skill everywhere. The Hub ships no third-party copywriting skill.

Left out:

- `lemy-setup`: one-time. It connects a repo and publishes the brand's shape, then removes itself. In no bundle, so no sync brings it back. Install it when needed: `npx skills add timschoch/lemy -s lemy-setup -y`.
- `lemy-brand`: brand rules, rarely needed. `tech-lemy-manage` includes this Bundle and adds it.
