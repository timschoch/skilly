# tech-lemy

Ships `lemy-write` from `timschoch/lemy`, plus the router rule `tech-lemy-write.md`. `lemy-write` is THE writing skill everywhere — no third-party copywriting skills anywhere in the hub.

Left out:

- `lemy-setup` — one-time: connects a repo and publishes the brand's shape, then removes itself. In no bundle, so no sync brings it back. Install it when needed: `npx skills add timschoch/lemy -s lemy-setup -y`.
- `lemy-brand` — brand rules, rarely needed; `tech-lemy-manage` includes this bundle and adds it.
