# GDD checkpoints

Good defaults, not law — the developer's word overrides anything here.

At each checkpoint, read [gdd](.agents/skills/gdd/SKILL.md) in full and run the named section. `.temp/gdd.json` is `declined` for this branch → skip every checkpoint.

| Checkpoint | Section |
| --- | --- |
| Before planning work with 3+ steps or architecture choices, no `.temp/gdd.json` for this branch | Session |
| Plan posted, concept shifted, a decision made | Drift check |
| Before `gh pr create` | Pre-PR check |
| `/gdd`, even when `declined` | Session |
