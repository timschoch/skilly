# tech-n8n

The official `n8n-io/skills` set (`-official` names only) plus two czlonkowski add-ons. Needs n8n >=2.2.0 with instance-level MCP, which our servers run.

15 skills, a recorded exception to the 3-4 skill cap for `tech-*`. The Bundle loads only in n8n repos, where nothing else competes for context.

Left out (2026-08-31):

- `n8n-io/skills` community-forked dupes (same names without `-official`): fewer installs, the official set wins.
- `czlonkowski/n8n-skills` other 12 skills: they overlap the official set and need the community n8n-mcp server.
- `WASD-Team/n8n-claude-skill`: no registry presence, one-commit history.
- `haunchen/n8n-skills-pack`: static node reference only. Add it if an offline lookup is ever wanted.
