# project-caffeinedealer

Stack bundle for `timschoch/caffeinedealer`: specialty coffee subscription shop for DACH and international markets on Shopify Basic + Appstle Subscriptions + Klaviyo + the Shopify Facebook & Instagram channel.

- `tech-shopify` — theme, Admin API, metafields, Shopify CLI.
- coreyhaines31/marketingskills, picked for a subscription shop: SEO (`seo-audit`, `ai-seo`, `schema`), conversion (`cro`, `pricing`), retention (`churn-prevention`, `referrals`), email flows (`emails`, written for Klaviyo), launch and positioning (`launch`, `product-marketing`, `content-strategy`).

Not `marketing`: it includes `tech-lemy` (lemy brand skills, private source) — wrong brand here.

No skill for Appstle Subscriptions or Klaviyo: neither ships a vendor skill repo (checked 2026-10-05). Klaviyo has an official MCP server — wire it in the consumer's `.mcp.json` instead.
